# homebrew Goblin

Веб-версия приложения для D&D-кампании: древо развития, классы, лист персонажа, книга заклинаний и правила для игроков; бестиарий, бой и игроки для мастера.

Открыть: https://slayrakul-art.github.io/homebrew-goblin/

Данные хранятся в браузере устройства. Перенос между устройствами — экспорт/импорт внутри приложения.
