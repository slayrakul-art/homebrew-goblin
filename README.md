# homebrew Goblin

Веб-версия приложения для D&D-кампании: древо развития, классы, лист персонажа, книга заклинаний, оружейная (1800 предметов, кукла персонажа, умный рандом) путь легенды (Пик и Синергия) и правила для игроков; бестиарий, бой и игроки для мастера.

Открыть: https://slayrakul-art.github.io/homebrew-goblin/

Данные хранятся в браузере устройства. Перенос между устройствами — экспорт/импорт внутри приложения.
